How a drop gets made

  1. 01Brief and merchandising input

    Sit with the line plan before anything is shot. What the drop is, how many pieces, what has to sell.

  2. 02Concept and copy

    One idea the whole drop can carry, written down as a line. If it can't be said in a sentence it isn't ready.

  3. 03Casting and location

    Cast and place chosen to match the concept, not the other way round. Recces before shoot days.

  4. 04Shoot direction

    Stills and film captured in the same session, from one shot list, so nothing has to be re-shot.

  5. 05Post and asset cutting

    One grade, then cut out to every format needed — 9:16, feed, product page — from the same master.

  6. 06Launch sequencing

    Order of release planned across feed, story and product pages so the drop lands as one moment.

One drop, every format

Movement × Adeel uz Zafar, every asset. Film stills, product shots, back prints, key art and launch coverage — all cut from one direction, so the drop reads the same everywhere it appears.
